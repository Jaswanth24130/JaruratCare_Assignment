# Mini Healthcare Support Web App (Full-Stack AI-Enabled)
Developed for Jarurat Care Foundation Internship Assignment[cite: 1].

## Architecture & Tech Stack
* **Frontend:** HTML5, Tailwind CSS, Modern UI Dashboard
* **Backend:** Node.js, Express.js (REST API endpoints for data intake & AI chat simulation)
* **Deployment Ready:** Configured for Vercel, Render, or Railway

## AI & Automation Features
* **Backend-Powered AI Summarizer:** Automatically processes incoming patient/volunteer form payloads and generates structured priority logs[cite: 1].
* **FAQ Chatbot Agent:** Responds dynamically via backend API routing to answer queries regarding rural health camps[cite: 1].

## NGO Use-Case
Streamlines patient intake and volunteer management for Jarurat Care Foundation by pairing a high-end frontend dashboard with a robust Node.js backend server[cite: 1].
